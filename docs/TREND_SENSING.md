# 에이블리 데이터 없이 트렌드 파악하기

판매 데이터 확보 전에도 돌릴 수 있는 3층 구조.
**핵심 원칙: 상류에서 후보를 발굴하고, 하류에서 검증한다.**

```
[상류] 동대문 도매 신상 → 신상마켓 업로드 (하루 3.5만 개)
          ↓ 2~4주
[중류] 셀러 사입 → 에이블리 등록 → 인스타/틱톡 노출
          ↓ 1~3주
[하류] 소비자 검색/클릭 → 네이버 쇼핑인사이트 · 검색어트렌드
```

| | 빠르기 | 정량화 | 노이즈 | 역할 |
|---|---|---|---|---|
| 상류 | ★★★ | ✗ 어려움 | 많음 | **후보 발굴** |
| 중류 | ★★ | △ 수기 | 중간 | 확산 확인 |
| 하류 | ★ | ✓ API | 적음 | **검증·추세** |

상류만 보면 오탐이 넘치고, 하류만 보면 늘 늦는다. 둘을 교차해야 한다.

---

## 1층 — 자동 수집 (코드, 무료)

### 1-1. 네이버 쇼핑인사이트 ★주력
**반드시 `gender=f`, `ages=["10","20"]` 세그먼트를 걸 것.** 전체로 조회하면
40~50대 구매력에 묻혀서 우리 고객과 무관한 신호가 나온다. 이 필터 하나로 체감이 완전히 달라진다.

- 키워드별 클릭 추이 (요청당 5개 → 앵커 체이닝으로 전체 비교 가능하게)
- 분야별 클릭 추이
- 성별/연령/기기 분해
- 월 5만 건 무료, 2017-08-01부터 조회 가능

쇼핑 **검색량**이 아니라 쇼핑 **클릭량**이라 구매 의도에 가깝다. 이 용도엔 좋은 성질.

### 1-2. 네이버 검색어 트렌드
쇼핑 맥락 밖의 관심도. 쇼핑인사이트와 **갈라지는 지점**이 의미 있다 —
검색은 느는데 쇼핑 클릭이 안 늘면 "화제성은 있으나 구매로 안 이어짐"(= 사입하면 안 됨).

### 1-3. 네이버 블로그/카페 문서 수
담론은 보통 구매보다 **선행**한다. 주별 문서 수 추이를 키워드별로 뽑고,
본문은 LLM 속성 추출(Phase 2)의 원재료로 쌓아둔다.

### 1-4. Google Trends (보조)
한국 지역 필터 + 연령 추정 불가라 한계가 있지만, 글로벌 유행이 한국에 상륙하기 전에
잡히는 경우가 있다. pytrends는 아카이브됐고 `trendspy`로 대체. 불안정하니 참고용.

## 2층 — 수기 관찰 (주 1회 30분)

> **솔직히 말해 초기엔 이게 어떤 모델보다 강하다.**
> 단, 기록 형식을 지금 정해둬야 나중에 모델 입력으로 쓸 수 있다. 메모장에 흘려쓰면 데이터가 안 된다.

### 매주 같은 요일·같은 시간에 기록할 것

**A. 플랫폼 랭킹 상위 50** — 에이블리, 지그재그, 무신사 우먼
→ 우리 고객이 실제로 뭘 사는지. 가장 직접적인 정답지.

**B. 신상마켓 신상 피드 / 인기 상품** ★상류 신호
→ 도매가 뭘 밀고 있는지. 여기서 반복적으로 보이는 디테일이 2~4주 뒤 랭킹에 올라온다.

**C. 인스타/틱톡** — 팔로우 중인 인플루언서 피드에서 반복 등장하는 아이템
→ 10~20대는 여기가 진짜 발원지. 정량화는 포기하고 "반복 출현"만 센다.

### 기록 스키마 (이대로 CSV에 쌓으면 그대로 학습 데이터가 된다)

```csv
observed_at,source,rank,item,silhouette,material,color,pattern,detail,style,price_krw,note
2026-10-21,ably,3,원피스,벌룬,새틴,블랙,무지,퍼프소매,로맨틱,29800,
2026-10-21,sinsang,,자켓,오버사이즈,트위드,아이보리,무지,골드버튼,프레피,42000,도매 여러 곳에서 동시 출현
```

- `source`: ably / zigzag / musinsa / sinsang / instagram / tiktok
- 속성 칸은 `config/taxonomy.yaml`의 값을 쓴다 (나중에 자동 매핑과 호환됨)
- 몰라도 비워둬라. 빈칸이 오답보다 낫다
- **`note`에 "여러 곳에서 동시 출현" 같은 메모가 제일 값지다**

### 왜 수기가 센가
플랫폼 랭킹은 API가 없어서 자동화가 안 된다. 그런데 그게 **정답지 그 자체**다.
주 30분 × 8주면 400행이 쌓이고, 그때부터 "네이버 지수가 올라간 속성이 실제로 랭킹에 올랐나"를
처음으로 검증할 수 있다. 이 검증 없이는 어떤 모델도 믿을 근거가 없다.

## 3층 — 거시 (월 1회)

- **KOSIS 온라인쇼핑동향조사** — 월간 의복 온라인 거래액(절대값). 상대지수를 절대 규모로 환산하는 앵커
- **삼성패션연구소 / 한국패션산업협회** 시즌 리포트 — 업계가 뭘 밀기로 했는지 (공급측 의도)
- 거시는 사입 결정을 바꾸진 않지만, "시장 전체가 줄고 있는데 내 지수만 오르는" 착시를 걸러준다
