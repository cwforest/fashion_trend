# 에이블리 판매 데이터 확보 체크리스트

친구분이 **my.a-bly.com 로그인 후 10분이면** 확인 가능한 항목들.
결과에 따라 시스템 Phase 3(캘리브레이션) 가능 여부가 갈린다.

> 조사 결과 에이블리는 셀러용 공개 API도, 공개된 판매자센터 매뉴얼도 없다.
> 모든 기능이 로그인 뒤에 있어 직접 확인하는 것 외에 방법이 없다.

---

## A. 꼭 확인할 것 (우선순위 순)

### A-1. 통계/분석 메뉴에 **엑셀(CSV) 다운로드** 버튼이 있는가  ★최우선
- 있으면 → Phase 3 가능. 시스템이 "참고용 신호"에서 "사입 결정 도구"로 올라감
- 없으면 → 화면 스크린샷 수기 입력 or 주문 내역 다운로드로 우회

확인 위치 후보: `통계`, `판매 분석`, `리포트`, `대시보드` 메뉴 안

### A-2. **상품 단위** 지표가 나오는가 (마켓 전체 합계 말고)
필요한 최소 조합:

| 지표 | 왜 필요한가 | 필수? |
|---|---|---|
| 상품별 **판매수량** (일/주 단위) | 예측 타깃 그 자체 | ★필수 |
| 상품별 **조회수** | 판매보다 선행. 조기탐지 정답지 | ★필수 |
| 상품별 **찜(좋아요)** | 구매의도 선행지표. 조회수보다 강함 | 권장 |
| 상품 **등록일** | 신상품 반응 속도 측정 | 권장 |
| 상품 **가격** | 가격대별 반응 차이 | 권장 |
| 상품명 / 카테고리 | LLM 속성 매핑의 입력 | ★필수 |

### A-3. **조회 가능 기간**
- 최소 **6개월**, 가능하면 12개월 이상
- 패션은 계절성이 지배적이라 1년치가 있어야 "작년 같은 시기 대비"를 볼 수 있다
- 3개월만 보관된다면 → **지금부터 매주 내려받아 쌓기 시작**해야 함 (이것만 해도 가치 큼)

### A-4. 다운로드 단위
- 일별인지 주별인지 월별인지
- 일별이면 최상. 월별만 되면 조기탐지 해상도가 떨어짐

## B. 있으면 좋은 것

### B-1. 주문 내역 다운로드 (정산/주문관리 메뉴)
통계 메뉴에 다운로드가 없어도, **주문 내역 엑셀**이 되면 그걸로 판매수량 시계열을 복원할 수 있다.
확인: `주문관리` 또는 `정산관리` → 기간 선택 → 엑셀 다운로드

### B-2. 광고 리포트
에이블리 광고를 집행 중이라면 `광고 성과 분석 → 엑셀다운로드`가 있다.
상품 단위 노출/클릭/전환이 들어있으면 조회수 대용으로 쓸 수 있다.
(단, 광고 집행 상품만 나오므로 전체 상품 커버리지는 안 됨)

### B-3. 플랫폼 전체 랭킹/인기 상품
내 마켓이 아니라 **에이블리 전체에서 뭐가 뜨는지** 보이는 화면이 있는가.
있으면 외부 신호 없이도 조기탐지가 가능해져서 네이버 의존도가 크게 줄어든다.

### B-4. ERP/솔루션 연동
사방넷·플레이오토 같은 통합관리 솔루션에 에이블리 연동이 열려 있는지.
(공개 자료로는 확인 안 됨 — 솔루션 업체에 직접 문의 필요)
연동되면 주문 데이터를 자동으로 끌어올 수 있다.

---

## C. 과거 사입 이력 (데이터센터 밖, 친구 머릿속)

시스템 학습에는 안 쓰더라도 **검증에는 이게 제일 값지다.**
- 최근 6~12개월 중 **크게 터진 상품 5~10개** — 품목, 떼온 시점, 왜 샀는지
- **죽은 상품 5~10개** — 품목, 떼온 시점, 왜 안 팔렸다고 보는지

이게 있으면 "우리 시스템이 그때 이걸 미리 잡았을까?"를 백테스트할 수 있다.
정량 데이터가 하나도 없어도 이것만으로 시스템의 쓸모를 1차 검증 가능.

---

## D. 하지 말 것

**에이블리 앱/웹 스크래핑.** 이용약관 위반 소지가 있고, 친구 계정이 걸려 있다.
파트너센터에서 합법적으로 받을 수 있는 경로를 먼저 다 확인한 뒤에 판단할 일이다.
